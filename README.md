クイック席替えメーカー

30秒で座席表が完成する、インストール不要の究極にシンプルなWebアプリです。
ブラウザひとつで動作し、複雑な設定なしで直感的に座席表を作成・印刷できます。

🌟 特徴

超高速入力: Excelや名簿リストから名前をコピー＆ペーストするだけで準備完了。

柔軟なレイアウト: クラスの人数に合わせて「6列×6行」などを自由に変更可能。

スマートな調整機能: 自動生成後、席をクリックするだけで入れ替えが可能。視力や相性などの配慮事項を直感的に調整できます。

印刷・PDF最適化: 印刷モードでは不要なボタンや入力欄が消え、A4用紙（横）にきれいに収まる座席表が出力されます。

インストール不要: HTMLファイル1つで動作するため、学校のPCやタブレット、スマホなど環境を選ばず使えます。

🚀 使い方

名前の入力: 「児童・生徒の名前」欄に名簿を貼り付けます（カンマまたは改行区切り）。

レイアウト設定: 縦・横の人数（行・列）を入力します。

生成: 「席替えを実行する」ボタンをクリックすると、ランダムに配置されます。

微調整: 生成された座席をクリックして選択し、別の席をクリックすると入れ替わります。

出力: 「印刷 / PDF保存」ボタンを押して、プリンターで印刷するか、PDFとして保存してください。
